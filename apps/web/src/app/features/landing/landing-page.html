How it works

Three steps, about thirty seconds, one credit.

  1. Step 1

    Open a symbol

    Search any NSE, BSE, NASDAQ or NYSE symbol and open it on the live chart.

  2. Step 2

    Get the read

    Trend state, the zones, volatility and the condition that would change the read. About thirty seconds, one credit.

  3. Step 3

    Keep it

    Save it in History, export it as a PDF, or add the symbol to Daily Briefing for a fresh read each morning.
